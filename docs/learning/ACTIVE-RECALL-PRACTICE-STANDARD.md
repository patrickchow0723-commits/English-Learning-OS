# Active Recall & Typing Practice Standard

> 版本：1.0  
> 适用范围：English Learning OS 的词汇、固定搭配、句型与商务表达课程。  
> 教学形式：Markdown 课程 + ChatGPT 对话；当前不要求开发前端。

## 1. 目标

把“看懂”逐步转化为“在真实工作场景中不看提示也能调用”。每个训练单元应至少经过理解、主动提取、纠错和迁移中的三个环节；重点表达应完成全部四个环节。

## 2. 四阶段练习循环

### A. Recognize — 理解与辨认

导师先展示少量表达，讲清：
- 含义与适用语境；
- 常见搭配和词性；
- 自然例句；
- 易混淆表达或中文母语者常见错误。

学习者先理解，不将“看过答案”记为掌握。

### B. Recall — 主动回忆

隐藏英文表达，只给中文含义、业务场景或句子缺口。学习者必须独立写出或说出英文。

提示梯度：
1. 无提示；
2. 场景提示；
3. 首字母或关键词提示；
4. 展示答案并解释。

记录最终使用了哪一级提示。只有无提示或低提示成功，才构成较强的独立提取证据。

### C. Dictate / Type — 听写或拼写

优先使用真实语音：导师播放/提供英文音频，学习者听后输入。若当前对话环境无法提供可播放音频，则改用“文本拼写重建”：导师给出中文释义、词义线索或打乱的句子片段，学习者输入英文。

必须区分：
- Audio dictation：真实听音后拼写，可形成听力与拼写证据；
- Text reconstruction：依据文字线索重建拼写，只形成词汇/拼写证据；
- Copy typing：照抄原文，只用于熟悉键入，不计为主动回忆或听力成绩。

### D. Transfer — 情境迁移

学习者必须将目标表达用于新的业务场景，例如：
- 向 HR 介绍自己的职责；
- 向客户澄清需求；
- 解释 AI 方案的技术取舍；
- 汇报项目风险与进度；
- 说明业务价值与 ROI。

迁移任务不要求逐字复用范文，但要准确表达同一核心含义。

## 3. 每轮训练规模

- 新授：每轮 5–8 个高价值词或表达。
- 单轮重点纠错：2–4 个错误模式。
- 每个表达至少有一个通用例句和一个与 Business × AI 工作相关的例句。
- 每轮至少安排一次无提示回忆和一次新场景迁移。
- 复习优先处理近期错误、长期未复测和跨场景迁移失败的项目。

## 4. 错误标签

导师按实际错误选择标签，可多选：

| 标签 | 含义 | 示例 |
|---|---|---|
| spelling | 拼写错误 | stakeholder 拼写不完整 |
| word_form | 词形错误 | coordinate / coordination 混用 |
| part_of_speech | 词性错误 | 需要名词却使用动词 |
| collocation | 搭配错误 | discuss about |
| preposition | 介词错误 | responsible of |
| tense | 时态错误 | 用现在时描述已完成项目 |
| grammar | 其他语法错误 | 主谓一致、冠词、从句结构 |
| meaning | 语义偏差 | 词义与业务意图不一致 |
| register | 语域不合适 | 对客户表达过于随意 |
| clarity | 表达不清晰 | 指代不明、句子重点不清 |
| pronunciation | 发音影响理解 | 仅在有可评估语音时使用 |
| listening | 听辨错误 | 仅在真实音频任务中使用 |

不要将内容事实错误与英语语言错误混为一谈；分别记录。

## 5. 判定规则

| 结果 | 判定 |
|---|---|
| correct | 核心含义正确，语法和搭配可接受，且未依赖答案 |
| partial | 含义大体正确，但存在明显词形、搭配、语法或表达缺口 |
| incorrect | 核心含义错误、无法完成或关键表达错误 |
| hinted | 依靠提示后完成；记录提示等级，不等同于独立正确 |
| skipped | 未尝试或主动跳过 |

可接受同义表达，不强迫学习者复述唯一标准答案。导师需说明“可接受表达”与“本课目标表达”的区别。

## 6. 掌握状态

- introduced：已讲解，尚无独立回忆证据。
- practicing：已有练习，但仍需提示或出现错误。
- developing：至少一次无提示正确回忆，但跨场景稳定性不足。
- verified：在不同日期、至少两个不同场景中无提示正确使用，并通过一次延迟复测。

“已掌握”不能仅凭一次跟读、照抄或选择题答对确定。

## 7. Evidence 最小记录

每个可追踪的练习项目至少记录：

- date / lesson_id / item_id
- mode：recognize / recall / audio_dictation / text_reconstruction / transfer
- prompt：本次提示
- original_response：学习者原始回答
- result：correct / partial / incorrect / hinted / skipped
- error_tags：实际错误标签
- hint_level：none / context / cue / answer
- corrected_response：纠正后的表达
- confidence：high / medium / low
- next_review_reason：为何安排复习
- next_review_at：若尚无调度器，可写“待复测”，不得伪造自动日期

除非确实写入外部存储，否则导师只称“本轮对话 Evidence”，不声称已经保存到数据库。

## 8. 复习规则（人工执行阶段）

在 FSRS 调度器经过实现和验证前，按以下启发式人工安排，不称为自动 FSRS：

- 本轮 incorrect：本课稍后再次回忆；
- 本轮 partial / hinted：本课末尾再测一次，并在下一次学习开头复测；
- 本轮 correct：安排不同场景迁移，之后做延迟复测；
- 已 verified：降低近期重复频率，但在综合任务中抽查。

复习安排必须说明原因，并根据下一次真实表现调整。

## 9. 导师每轮输出格式

1. 本轮目标与表达清单；
2. 学习者原始回答；
3. 结果与错误标签；
4. Corrected：准确版本；
5. Natural：自然商务版本（需要时）；
6. Reusable pattern：可迁移句型；
7. 本轮 Evidence；
8. 下一轮复测项目。

## 10. 音频与评分边界

- 没有实际音频输入/输出时，不标记为完成听力听写。
- 没有学习者语音时，不评分发音、语调或口语流畅度。
- 文字输入可评估拼写、词汇、语法、组织和商务得体性。
- 语音任务可增加发音可理解度、停顿和流畅度，但需引用实际语音证据。
