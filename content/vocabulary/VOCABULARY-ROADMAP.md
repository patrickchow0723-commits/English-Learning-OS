# Vocabulary Curriculum Roadmap

## 目标

建立能服务于日常职场、商务管理、软件工程和 AI 业务落地的主动词汇系统。词汇数量是内容建设目标，不是能力证明。

## 词汇层级

| 层级 | 目标规模 | 内容 |
|---|---:|---|
| Core English | 1,000 | 高频动词、名词、形容词、介词与功能词 |
| Workplace English | 800 | 沟通、协作、计划、反馈、交付 |
| Business English | 700 | 战略、市场、客户、财务、运营、谈判 |
| Technology English | 500 | 架构、软件交付、云、数据、安全 |
| AI & Leadership English | 500 | LLM、Agent、治理、ROI、转型、管理 |

总目标约 3,500 个词条。初期优先建设高频且可主动使用的词汇，而非一次性堆满词表。

## 每个词条的数据规范

- word：词条
- part_of_speech：词性
- pronunciation：IPA（有可靠依据时）
- plain_definition：简明英文释义
- zh_translation：中文释义
- collocations：常见搭配
- example_general：一般语境例句
- example_work：职场语境例句
- example_ai_business：AI/商业语境例句（适用时）
- register：formal / neutral / informal
- level：基础 / 中级 / 高级
- common_error：中文母语者常见误用（有把握时）
- status：introduced / practicing / developing / verified

## 教学原则

1. 每次新授 5–10 个词，优先掌握词块和搭配。
2. 必须能够在自己的工作语境中造句。
3. 区分认识词汇（passive）与能够即时调用的词汇（active）。
4. 避免把生僻词、复杂词误当成高级商务表达。
5. 不为凑数量重复收录同义词或低价值变体。

## 首批优先主题

1. Explain / describe / clarify / confirm
2. Lead / manage / coordinate / deliver
3. Identify / prioritize / address / resolve
4. Align / agree / propose / recommend
5. Scope / requirement / constraint / dependency
6. Outcome / impact / value / result
7. Risk / issue / blocker / mitigation
8. Adopt / implement / integrate / scale
9. Estimate / allocate / optimize / measure
10. Stakeholder / ownership / accountability / roadmap

## 词汇学习验收

学习者能够：
- 理解词义与语气差别；
- 识别常见搭配；
- 在不看提示时造出正确句子；
- 在至少两个不同工作情境中恰当使用。
