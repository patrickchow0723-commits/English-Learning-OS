# English Learning OS

面向国际化职场的商务英语学习课程库。当前阶段只维护 Markdown 课程与学习资料，不开发前端。

## 学习目标

帮助学习者在真实工作中使用英语完成：
- 自我介绍、求职面试与职业经历陈述
- 商务会议、需求澄清、方案讨论与决策
- AI 产品、企业 Agent、技术架构与商业价值表达
- 项目管理、跨团队协作、风险沟通与谈判
- 商务邮件、项目报告、演示与管理层汇报

## 学习方式

课程通过 ChatGPT 对话进行。用户说“开始英语学习”或指定课程编号时，导师读取对应课程，按课程流程教学、布置练习、纠错并记录本轮 Evidence。

## 课程原则

1. 先能表达，再追求复杂和地道。
2. 以真实工作任务为中心，不堆砌脱离场景的词汇。
3. 每个新表达都进入主动输出练习。
4. 评价语法、词汇、清晰度、流畅度、发音可理解度和商务得体性。
5. 不虚构学习成绩；能力变化必须由实际回答和复测支持。
